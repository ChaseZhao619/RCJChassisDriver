# BSP 模块说明与调参指南

本文档说明 `Bsp/Inc` 与 `Bsp/Src` 中各模块的职责、坐标约定、可调参数和建议调试流程。所有电流值均为大疆 C610/C620 协议中的控制量，并非毫安；实际电流换算应以所用电调手册为准。

## 调试前的通用规则

1. 架空底盘，先验证电机编号、旋转方向、反馈方向和急停逻辑，再落地调试。
2. 同一时间只启用一个 `*_TEST_ENABLE`，测试结束后将其恢复为 `0U`，避免多个测试任务争用执行器。
3. 先用较小的 `MAX_CURRENT` 和速度上限确认方向，再逐步增加。方向错误不能通过 PID 参数修正。
4. 每次只改一组参数，记录电池电压、负载、目标值、实测值及现象；否则无法判断改动来源。
5. 下文的“增大/减小效果”是控制理论上的一般趋势，最终值必须以实车波形、温升和机械状态为准。

## 坐标系与正方向

- 底盘平移：`forward` 为车体前方，`left` 为车体左方。
- 极坐标方向：`0 deg` 为前方，`90 deg` 为左方，角度按逆时针增加。
- 旋转：`ccw` 为从上向下看逆时针。
- 里程计世界坐标：`x`、`y` 分别由车体速度结合当前偏航角积分得到；调用者必须持续提供同一约定下的 `yaw_deg`。
- 若某轴运动方向、编码器反馈或陀螺仪符号不符，优先修改对应的 `*_DIR`，不要用负 PID 参数补偿。

## 推荐调参顺序

### 1. 电机与方向

使用 `bsp_motor_test` 的小电流逐个确认 CAN ID 1~5。确认底盘四个轮子的 `BSP_CHASSIS_MOTORx_DIR` 后，再确认 `BSP_CHASSIS_MOTORx_FB_DIR` 能使“正目标速度对应正反馈速度”。功能电机同理检查 `BSP_KICK_MOTOR_DIR` 与 `BSP_KICK_MOTOR_FB_DIR`。

### 2. 底盘轮速环

暂时关闭角度保持并架空底盘：

1. 将 `KI`、`KD` 置零，`KF` 从较小值开始，使中高转速下的基础输出接近目标。
2. 增大 `KP`，直到跟随足够快且尚未出现持续振荡；出现高频抖动时回退。
3. 缓慢增加 `KI` 消除稳态误差。若启停后输出长时间不回零，减小 `KI` 或 `I_LIMIT`。
4. 只有确认噪声可控且确有超调需求时才增加 `KD`。编码器速度噪声会被微分项放大。
5. 最后在负载和低电量条件下复测 `MAX_CURRENT`、温升和堵转保护。

### 3. 偏航角保持

先确认 `BSP_CHASSIS_GYRO_Z_DIR` 和 `BSP_CHASSIS_YAW_CTRL_DIR`：人为逆时针转动车体时，逻辑角速度及控制输出应符合注释中的正方向。

1. 从较小 `ANGLE_KP` 开始，提高到回正速度满足要求。
2. 若接近目标仍来回摆动，增大 `ANGLE_GYRO_KD`；若响应迟钝或无法快速回正，适当减小。
3. 静止抖动先检查 IMU 噪声，再调整 `GYRO_DEADBAND_DPS` 和 `ANGLE_DEADBAND_DEG`。
4. 小误差克服不了静摩擦时提高 `ANGLE_MIN_RPM`；过高会造成目标附近极限环。
5. 用 `ANGLE_MAX_RPM` 和 `ANGLE_MAX_CURRENT` 设置最终安全上限。

### 4. 运动耦合补偿

将车头锁定，在平整场地分别执行纯前进和纯左移。纯前进发生稳定横漂时调整 `FORWARD_TO_LEFT_COMP`；纯左移发生稳定纵漂时调整 `LEFT_TO_FORWARD_COMP`。该补偿只修正近似线性、可重复的机械耦合，不能代替轮速环或解决轮胎打滑。

### 5. 里程计比例

先准确测量轮径和减速比，再进行长直线标定：

- `实际距离 / 里程计距离` 可作为当前方向比例系数的乘法修正量。
- 前后方向修正 `BSP_CHASSIS_ODOM_FORWARD_SCALE`，左右方向修正 `BSP_CHASSIS_ODOM_LEFT_SCALE`。
- 至少双向各测多次并取平均，避免地面坡度、轮胎打滑和偏航误差影响结果。
- 比例正确后再调 `POS_KP`、最小速度、最大速度和到点容差。

## 传感器调参注意事项

### BE1732

`NO_BALL_VALUE_THRESHOLD` 是最强通道值低于或等于多少时视作一次“无球”；`NO_BALL_COUNT_LIMIT` 是连续多少次无球后才输出无球。后者对应的实际消抖时间为：

```text
无球确认时间 = 调用 BspBe1732_ReadFilteredChannel() 的周期 × NO_BALL_COUNT_LIMIT
```

阈值应采集“无球环境噪声”和“最远有效球信号”后选在两者之间。更高阈值更容易判无球；更大的计数限制更稳定，但丢球响应更慢。阈值写入 Flash，频繁写入会消耗擦写寿命，只应在参数确实变化时保存。

### BNO085

报告周期 `interval_us` 越短，姿态更新更快，但 I2C 占用和 MCU 解析负载越高。主循环必须足够频繁读取，否则传感器缓冲区可能积压。先用较慢周期确认通信稳定，再按控制带宽缩短；角度环的有效带宽不应高于姿态数据实际更新率。

### 吸球检测

`BSP_SUCTION_DETECT_ACTIVE_LEVEL` 只配置逻辑极性。若传感器输出会抖动，应在任务层按固定周期连续采样并做计数消抖，不能通过 GPIO 上拉/下拉替代时间滤波。

## PWM 吸球电机安全说明

`BspSuctionMotor_Init()` 使用初始化脉宽使 ESC 进入可接受状态；只有完成电调说明书要求的上电/解锁流程后才能提高脉宽。`INIT_MIN/MAX_US` 与 `RUN_MIN/MAX_US` 是协议范围，不代表具体电机在该脉宽下一定安全。首次测试应拆除负载或采取防护，从低脉宽逐级增加并观察电流、温升和机械振动。

## 测试代码使用原则

- `bsp_motor_test`：低电流逐个验证 CAN 电机和方向。
- `bsp_chassis_test`：验证四轮合成运动及偏航保持。
- `bsp_chassis_angle_test`：专用于角度环，落地前先架空确认控制方向。
- `bsp_chassis_odom_calib_test`：用于固定距离的前后/左右比例标定。
- `bsp_chassis_odom_test`：按场地边界运行，必须先确认场地尺寸、车体尺寸和急停手段。
- `bsp_suction_motor_test`：逐级改变 PWM，测试时限制最大脉宽。

测试宏为 `1U` 时可能在上电后自动驱动执行器。烧录前应检查所有测试头文件，并确认只有预期测试处于启用状态。
